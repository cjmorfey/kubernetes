# Архів першої версії

Ці CentOS, Docker, NFS, Java 8, Zabbix, Dashboard та допоміжні Jenkins
сценарії збережені для історії. Вони не підтримуються та не запускаються
командою `./cluster`. Їхні старі шляхи, пакети та зовнішні залежності можуть
бути неактуальними; деякі виконують руйнівне очищення або вимкнення машин.

Для Ubuntu використовуйте інструкцію в кореневому README. Jenkins job-и,
які посилаються на переміщені файли, потрібно вимкнути у вашому Jenkins;
основна заміна — `kube-cluster/jenkins-jobs/K8S_create_cluster.jenkins`.
